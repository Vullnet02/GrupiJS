Ky kod tregon disa mënyra bazike për të ruajtur dhe përdorur të dhëna në JavaScript: Object, Array dhe JSON.


Object përdoret për të ruajtur informata për një element të vetëm në formën key : value. Në shembullin student, ruhen të dhëna për një student si emri, mosha dhe qyteti. Kjo na ndihmon të organizojmë informata që i përkasin një objekti të vetëm dhe t’i aksesojmë lehtë (p.sh. student.name).


Array përdoret për të ruajtur një listë elementesh. Në shembullin fruits kemi një listë me fruta dhe mund t’i marrim ato sipas pozicionit të tyre (index), p.sh. fruits[0].


Array of Objects është një kombinim shumë i përdorur në aplikacione reale. Këtu kemi një listë studentësh ku secili student është një objekt me të dhënat e veta. Kjo përdoret shumë në API, databaza dhe aplikacione si React.


JSON (JavaScript Object Notation) është një format për transferimin e të dhënave. JSON.stringify() e konverton një objekt në tekst JSON për ta dërguar në server ose API, ndërsa JSON.parse() e kthen përsëri JSON në objekt JavaScript për ta përdorur në kod.

Në përgjithësi, këto struktura na ndihmojnë të ruajmë, organizojmë dhe përdorim të dhëna në mënyrë më të rregullt në aplikacione web dhe programe JavaScript.
